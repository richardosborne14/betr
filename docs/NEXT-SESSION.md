## 4. Gotchas, live

- **`node --test web/tests/` does not work on Node 22** — run it from the repo root.
  `harness.js` is the fake DOM; `boot(seed, { timeZone, languages })` is the phone it pretends
  to be (London, English). In its `vm`, **`instanceof Array` is unreliable** and there is **no
  `crypto`** — hence `store.rid()`'s `Math.random` fallback.
- **A walk in a test goes through a door now**: `#go` → `[data-door]` → `[data-id]`. Nothing in
  a test may hard-code the first worry's words; use `doors.items[n].worries[0]` and look it up.
  `loop.test.js`'s header has said this since B1 and three assertions had drifted anyway.
- **`content.test.js` holds `STARTS_TODAY` by hand.** The first worry behind every door has to
  be one a person can start on the day they tap it, or their first loop ends in *Didn't get to
  it*. It is a judgement per test, not derivable, so it lives in the test and shows in a diff.
- **A worry behind no door is unreachable**, and `validateDoors` fails the build on it. A door
  is **four fields and no fifth** (`note` is the optional one, and it is a safety line).
- **Every word a person reads is in `web/content/strings-en.js`**; a sentence back in `app.js`
  fails `i18n.test.js`, as does a `left:` or a `px` font size in `app.css`.
- **Every screen goes through `paint()`**: it appends the menu, moves focus to `#top` and
  speaks anything `say()` left. Setting `app.innerHTML` loses all three.
- **Content is `web/content/*.js`, not `.json`**, and `web/lib/*.js` are classic scripts: a
  browser will not fetch JSON or load an ES module off disk. A test may **read** content out of
  there, never restate it; and a locked-in test keeps its own copy of the words, so **clear
  storage** before checking a content edit in a browser.
- **A new field on the stored state goes in three places**: `blank()`, `normalise()`,
  `isEmpty()`. (A field on a *record* inside `done`/`open` is `normalise()` only.)
- **Storage is v3.** **A ladder's rungs come from `g.rungs`, not `r.level`.** Reading `r.level`
  in a renderer is the bug B9 nearly shipped. The v1 `rate` migration must stay.
- **`content/zones.js` is generated, never hand-edited**, and **no helpline number is written
  from memory** — off the provider's site that day, with the URL and the date, or leave the
  country out. **Sentence 7 names 988 and 116 123 inside itself**: frozen.
- **Language and country are two separate questions.** **The ladder is one belief's grip** — no
  total, no average, no target, on screen or out loud. **`.kicker` is uppercase in CSS**, so
  `innerText` shouts. **The guard blocks "bet"** — see Q1.
- **iPhone Safari deletes a page's storage after seven days unused** — install card and
  `navigator.storage.persist()` are in; the real fix is B5's native wrap (research §9.1).
- **A link is allowed; a request is not** — `menu.test.js` holds the allow-list.
- **`content/why.js` has two fields and no third** — the regulatory line, not a style rule. It
  may never read `S.done`, a rung, a re-rate or a missed test, and an explanation may never
  outlive the worry it explains. `about` is taken as a stage name, so the screen is `why`.
